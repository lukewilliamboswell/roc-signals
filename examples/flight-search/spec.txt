# Flight search: filters are effect triggers, sorting is a derived view.
#
# Every `select_option label:"Sort by" ...` in this spec is followed by
# `expect_pending_task "flight-search" 0`, proving a sort never refetches.
# Every filter change is followed by `expect_pending_task "flight-search" 1`,
# proving a filter always does.

# --- initial mount -----------------------------------------------------------
