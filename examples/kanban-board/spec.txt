# Kanban board: keyed rows moved across columns and reordered within a column,
# with derived per-column counts, WIP limits, and a text filter.
#
# The metric blocks are the point of this example: moving one card between two
# columns creates exactly one row and removes exactly one row, and every other
# row in both columns is reused. Reordering inside a column reuses every row.
