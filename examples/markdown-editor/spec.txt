# Markdown Editor
#
# One markdown source string feeds four independently derived views: the
# rendered preview, the table of contents, the raw counts, and the reading
# estimate. This spec asserts the full initial render, drives every
# interaction, walks the edge cases (empty source, no headings, nested and
# skipped heading levels, duplicate headings, markup lookalikes), and pins the
# fine-grained update budget with metric deltas.
#
# The app has no async work, so there is nothing here for resolve_task /
# reject_task / resolve_stale_task to cover.

# ---------------------------------------------------------------------------

# ---------------------------------------------------------------------------
