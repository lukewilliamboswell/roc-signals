# Recipe Scaler
#
# One servings input drives dozens of independent derived leaves. The point of
# this spec is that a servings edit patches exactly the ingredient quantity
# sinks and does nothing structural: no rows created, reused, removed, no
# scopes mounted or disposed.
#
# Quantities are integers in a fixed-point unit (micro-units per serving,
# scaled by milli-servings, rounded to hundredths for display), so every value
# below is exact on every host.

# --- The fan-out: one input, many leaves, nothing structural -----------------

# 5 ingredient sinks + 9 shopping sinks + the two summary lines + the input's
# own value sink all recompute from a single servings edit. No row is created,
# reused or removed, and no scope is mounted or disposed, because neither
# each_str list signal depends on servings: the row items carry per-serving
# amounts, and the target scale reaches them as a separate signal.
# Observed here: dirty_source_roots 1 (one dirty source root), patches_emitted 17
# -- exactly the 14 quantity sinks, effective-servings, scale-note, and the
# servings input value. Nothing structural.
