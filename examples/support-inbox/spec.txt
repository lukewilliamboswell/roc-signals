# Support Inbox
#
# Wire format for the "inbox" sync task:
#   <conversations> # <messages>
#   conversation: id|subject|customer|owner
#   message:      id|conversation|author|body|read-flag|client-id
#
# The "send" task echoes the client id on both success and failure.
#
# Product decisions this spec locks in:
#   - Filtering never closes the open thread. The row can leave the list; the
#     thread pane stays put and a notice explains the mismatch.
#   - A message keeps its client id as its row key for its whole life, so the
#     server acknowledgement reuses the row instead of recreating it.
#   - Only one send is ever in flight; the composer stays disabled while a send
#     is pending and while a failed send is waiting to be discarded.
#   - A conversation the inbox no longer lists shows an empty thread.
