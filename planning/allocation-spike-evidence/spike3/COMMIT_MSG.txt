Add Ui.each_template, a stage-one static row template

Prototype for issue #39, stage 1 only, on provisional names. A builder runs once
for a site and returns static elements, text and attributes, with TemplateRow
placeholders for the exact key. Ui.each_template is a thin wrapper over Ui.each:
the row closure returns RowTemplate, holding one shared Box(Elem) plus the key,
so the retained row callable is the template's one explicit owner, and Ui.each
itself is unchanged.

The engine resolves key placeholders during the row's ordinary collection, which
copies every byte into the same descriptors a literal row produces. Scopes,
identity, transactions and teardown are unchanged. A template holding anything
but static structure is a contract error at collection.

Commands are byte-identical to the equivalent Ui.each row across mount, create,
append, replace and clear. No wire change. Metrics schema 7 adds
row_template_instances and row_template_subtrees.

This does not cover the js-framework-benchmark row, whose label, selection and
events are stages 2 and 3.
