# 0.2.0-rc3

## Migration: 0.2.0-rc2 → 0.2.0-rc3

This is the first combined Roc Signals release candidate. It publishes two
distinct platform packages under one immutable GitHub Release: a web package
for browser applications and native semantic tests, and a fat GUI package for
Linux x86_64, Apple Silicon macOS, and Windows x86_64 applications. Web and GUI
remain different platform APIs. Use separate application roots and the separate
platform URLs recorded in `signals-examples.zip`.

Use Roc `nightly-2026-09-04-c125b82`, as recorded in every example header and
`signals-release.json`. The fat GUI package expands beyond Roc's default package
budget, so GUI builds from its URL currently require
`--max-transitive-mb=512`. This is an explicit release-candidate workaround;
future host-size work should remove it.

## Immutable build inputs

The release workflow builds no Rust or Zig host code. It downloads and
SHA-256-verifies independently published web hosts, GUI hosts, and external
linker inputs, including the reviewed macOS TBD catalog, then runs `roc bundle`
once for each platform. Linux, macOS, and Windows runners serve those same two
candidate archives on localhost and run the extracted example smoke tests before
one publishing job can create the prerelease.

The release manifest records the exact input locks, platform and example asset
digests, source commit, compiler pin, and final URLs. GitHub attestations accompany
the final assets as optional provenance; normal consumption relies on the
reviewed content hashes and does not require an attestation service.
