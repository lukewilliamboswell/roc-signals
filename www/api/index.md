# Roc Signals API

The modules the web platform exposes to apps: `Engine` (programs, state,
values, handlers, structure, keyed lists, components and effects), `Html`
(typed HTML elements, attributes and events over `Engine.element`), `Worker`
(pure programs run in Web Workers, and the layers that show their answers)
and `Wire` (the binary format their inputs and outputs cross in, derived
from their types).
