{# What a turn does, as four steps along one wire: the first node is the write, and nothing follows the last. #}

  1. 01 · Write

    A handler writes a state, a store cell or a table row, and says what it touched.

  2. 02 · Propagate

    One pass runs only the sites that read it, each once, in nesting order.

  3. 03 · Patch

    Exactly those DOM nodes are updated. There is no virtual DOM.

  4. 04 · Verify

    The same engine runs natively, so every behaviour is a spec you can run without a browser.
